# Блокировщик мразей

Расширение для Chrome/Edge (MV3), которое помогает быстро блокировать людей
в Facebook и отмечать их для себя, чтобы не вступать с ними в контакт и не
сотрудничать.

## Зачем этот проект

Проект помогает не сотрудничать и не взаимодействовать с людьми, поддерживающими
хуйло, рашку, её агрессию против Украины, геноцидальную политику и российский
империализм. Пользователь может блокировать такие аккаунты в Facebook и
отправлять запросы на блокировку аккаунтов, указывая подтверждающий пост или
комментарий. В дальнейшем проект планируется дополнить общей базой таких
аккаунтов и рассмотрением пользовательских запросов.

Основанием для решения должны быть публичные слова и действия самого человека:
например, одобрение вторжения и оккупации, оправдание военных преступлений,
призывы к насилию, поддержка российской военной агрессии или распространение
имперской пропаганды. Пассивная поддержка тоже может проявляться в публичных
действиях — например, в распространении такой пропаганды или одобрении
публичных символов и кампаний войны.

Блокировка применяется к гражданам любой страны, в том числе Украины. Основанием
может быть, например, положительная реакция на комментарий, который одобряет
агрессию, военные преступления, насилие или российский империализм. При отправке
запроса укажите публикацию или комментарий, на котором основана оценка.

## Как пользоваться

1. Откройте список «Нравится» (клик по реакциям под комментарием).
2. Справа внизу появится панель 🚫 «Блокировщик мразей» со счётчиком найденных людей.
3. Первый прогон сделайте с галочкой **«Тестовый прогон»** — расширение дойдёт
   до кнопки «Подтвердить», но нажимать её не будет.
4. Нажмите **«Блокировать всех»**. Расширение обрабатывает людей по очереди:
   для каждого — «…» → «Заблокировать» → «Подтвердить», со случайной паузой
   2–6 с между людьми (настраивается) и длинными паузами каждые N человек.
5. История заблокированных хранится локально (повторно не блокируются).

## Только выбранная вкладка реакций и ручная проверка

- Расширение **никогда не сканирует страницу в фоне**: список собирается только
  по кнопке «↻» (Обновить) или при запуске прогона.
- Сверху панели видно **открытую вкладку реакций** («Показать 37 человек, …
  Нравится») и **список имён** — ровно те строки, что сейчас загружены в окне,
  в том же порядке отображения. Сверьте его — и запускайте.
- Галочка **«Блокировать только то, что видно в списке»** (включена по умолчанию)
  запрещает автопрокрутку: блокируются только загруженные строки. Прокрутили
  список — нажмите «↻» снова. Снимите галочку, чтобы прогон сам доскроллил
  до конца вкладки.

Режим «Через вкладки профилей» — быстрая альтернатива: профили открываются
**параллельно, пачками до 100 вкладок** (настраивается полем «Вкладок
одновременно»), и в каждой вкладке выполняется та же цепочка
«…» → «Заблокировать» → «Подтвердить». После завершения пачки все вкладки
закрываются, затем идёт следующая.

В режиме «В открытом списке» строки с кнопкой «…» обрабатываются по очереди
(так быстрее и без вкладок), но люди, для которых Facebook не даёт меню «…»
(не-друзья), копятся и блокируются **параллельно** в служебных вкладках —
пачкой до значения «Вкладок одновременно». Пачка отправляется сразу после
прохода по загруженным строкам, а не в самом конце прогона.

## Как расширение понимает, что блокировка удалась

После нажатия «Подтвердить» Facebook часто показывает не закрытие окна, а
**окно успеха «Вы заблокировали X…»** (с текстом «Другие профили X не будут
заблокированы, но мы ограничим для этого пользователя возможности
взаимодействия с вами в них»). Расширение:

- распознаёт это окно как **успех** и берёт имя именно из него (поддерживается
  и английский интерфейс — «You blocked …»);
- сверяет имя в окне успеха с ожидаемым: если это другой человек — результат
  помечается ошибкой, а не «успехом»;
- **закрывает окно успеха** («Закрыть»), потому что модалка перекрывает список
  и без этого следующие строки нажать нельзя. Заодно закрываются «зависшие»
  окна успеха от предыдущих блокировок;
- если окно успеха не появилось, но окно «Заблокировать X?» закрылось —
  блокировка тоже считается успешной.

Если у человека в строке нет кнопки «…» (Facebook не даёт меню для не-друзей),
расширение автоматически блокирует его через вкладку его профиля — и в точечном
режиме (кнопка «🚫»), и во время общего прогона по списку.

## Установка

1. `npm install` (нужно для тестов; самому расширению зависимости не нужны).
2. Откройте `chrome://extensions` → «Загрузить распакованное расширение»
   → выберите папку проекта.

## Тесты

- `npm test` — 37 юнит-тестов (jsdom + точная разметка Facebook из `test/fixture/`):
  ключи профилей, распознавание окна «Заблокировать X?», кнопки «Подтвердить»/
  «Отмена», сбор строк списка, триггеры «…», окно успеха «Вы заблокировали X…»
  (распознавание, имя, закрытие, чужое имя), параллельные пачки вкладок
  (ровно `maxTabs` одновременно, потолок 100), полный сценарий блокировки с
  симуляцией ответов Facebook, dryRun, отмена при несовпадении имени.
- `npm run test:e2e` — e2e-тест в настоящем Chrome (Chrome for Testing
  скачивается в `.chrome/` при первом запуске): загружает расширение, открывает
  эмулированный список из 5 человек, нажимает «Блокировать всех» и проверяет,
  что все 5 заблокированы через полную цепочку «…» → «Заблокировать» →
  «Подтвердить», а окна успеха «Вы заблокированы X…» распознаны и закрыты.

## Структура

- `manifest.json` — MV3, permissions: storage, tabs; content scripts на facebook.com.
- `src/util.js` — утилиты, лог, настройки, история заблокированных (chrome.storage).
- `src/fb-dom.js` — работа с DOM Facebook: поиск списков, окон, кнопок, ключей профилей.
- `src/engine.js` — движок: режимы «список» и «вкладки», паузы, статистика.
- `src/panel.js` — панель управления (Shadow DOM, не ломается стилями FB).
- `content/content.js` — точка входа content-скрипта (+ обработчик служебных вкладок).
- `background.js` — service worker: открытие/закрытие служебных вкладок, счётчики.
- `popup/` — всплывающее окно с историей.
- `test/fixture/facebook-markup.js` — точная разметка Facebook (из реальных
  инспекций) для юнит- и e2e-тестов.

## Важно

Facebook часто меняет классы и структуру DOM. Расширение опирается в первую
очередь на aria-атрибуты и роли (`role="menuitem"`, `aria-label="Подтвердить"`),
которые стабильнее классов, но при крупных изменениях интерфейса селекторы
(`src/fb-dom.js`) может понадобиться обновить. Используйте паузы по умолчанию:
слишком быстрый массовый прогон может привести к временной блокировке действий
со стороны Facebook.
